# PBL_Smart_Transport_Monitor_Fase_5_FIAP
Cidade Alfa — Smart Transport Monitor Projeto do desafio FIAP para análise da frota autônoma da Cidade Alfa. O objetivo é higienizar dados brutos, imputar valores ausentes e calcular métricas de pontualidade, consumo de bateria e status dos sensores, gerando uma base tratada para a tomada de decisões da gestão urbana.
