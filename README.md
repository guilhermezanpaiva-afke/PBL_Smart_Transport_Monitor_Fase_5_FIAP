# PBL_Smart_Transport_Monitor_Fase_5_FIAP

Projeto desenvolvido para o desafio da FIAP para análise da frota autônoma da Cidade Alfa. O objetivo é higienizar dados brutos, imputar valores ausentes e calcular métricas operacionais — como pontualidade, consumo de bateria e status dos sensores — utilizando **Pandas** e **NumPy** para gerar uma base tratada voltada à tomada de decisões na gestão urbana.
